# Theatrle

This program is a game similar to wordle but with the titles of famous movies.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download the APK file on your android phone. (You may need to change phone settings to allow unknown or unverified APK files)
2. Install the application onto your phone by running the APK file.

Instructions for using the software:

1. Launch the app.
2. Guess the movie title.
3. Use the clues given to your guess to keep guessing.
4. Guess the title in less than 6 guesses.
